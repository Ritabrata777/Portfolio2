# TARS

Desk robot that chats, reports weather, and reacts on a tiny screen.

## Problem it solves

Embedded AI feels abstract until it talks back. TARS makes it tangible and fun.

## How it works

1. ESP8266 connects over Wi-Fi and pulls weather plus prompts.
2. Gemini API generates short conversational replies.
3. OLED shows faces, text, and status with Arduino-driven timing.

## Tech stack

- ESP8266, OLED, Arduino firmware
- Gemini API conversation layer

## Key features

- Voice-like chat on microcontroller
- Weather plus personality display
- Great demo for embedded AI
