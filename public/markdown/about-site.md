# About This Portfolio

This portfolio is intentionally built like a macOS desktop instead of a standard scrolling website.

## Why this format

- It makes the portfolio feel interactive and memorable
- It lets projects, notes, browser links, and terminal content live inside separate app windows
- It reflects Ritabrata's interest in interface design, prototyping, and playful product experiences

## What to explore

- **Bear** for structured notes and project summaries
- **Terminal** for a full file-based profile
- **Safari** for live links and tooling references
- **VSCode** for a quick technical snapshot

The goal is to make the portfolio feel closer to a product demo than a resume page.
